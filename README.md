# Заявки на пропуск

Заготовка Android-приложения сотрудника для работы с заявками на посещение организации. Приложение предназначено для входа по коду, просмотра и создания заявок, просмотра деталей и отмены заявки на рассмотрении. Решение охраны отображается после обновления данных.

Проект написан на Kotlin с использованием Jetpack Compose. Для работы с сервером используется Ktor Client, для хранения кода входа — DataStore. Контракт сервера описан в [openapi.yaml](openapi.yaml). Условия задания и порядок сдачи приведены в [TASK.md](TASK.md).

## Требования

- JDK 17 и Android SDK с платформой API 36.
- Android Studio для запуска приложения на устройстве или эмуляторе.
- Устройство или эмулятор с Android API 26 или новее.
- Работающий сервер, доступный приложению.

## Сборка и запуск

1. Откройте проект в Android Studio и дождитесь синхронизации Gradle.
2. Запустите сервер. Адрес сервера задан в `app/src/main/java/ru/nto/guestmanagement/mobile/Constants.kt` в `Constants.HOST`. По умолчанию используется `http://10.0.2.2:8080` — порт 8080 компьютера, доступный из Android-эмулятора. Если сервер находится по другому адресу, укажите адрес, доступный с устройства.
3. Выберите устройство или эмулятор и запустите конфигурацию `app` в Android Studio.
4. На экране входа введите четырёхсимвольный код сотрудника, выданный для используемого сервера.

Для сборки debug-версии из корня проекта выполните:

```bash
./gradlew assembleDebug
```

APK будет находиться в `app/build/outputs/apk/debug/`.

В заготовке нет тестов. Для запуска собственных локальных тестов выполните:

```bash
./gradlew :app:testDebugUnitTest
```
